# Contract — amendment to the canonical events

**Covers**: FR-002, FR-011, FR-013, FR-026 | **Amends**:
`specs/006-replay-analysis-foundations/contracts/canonical-events.md` | **Research**: R1, R4

Additive only. No kind is removed, no field changes type, and 006's golden timeline must come back
byte-identical through the amended adapter.

## `unit-queued` carries every producing building

| Field | Type | Rule |
| ----- | ---- | ---- |
| `building_objects` | tuple of object ids, non-empty | Every producing building the command names, in the engine's order. |
| `building_object` | object id | Unchanged: the first of `building_objects`. Kept so no consumer moves. |

The register gains `event.unit_queued.building_objects`. The narrowing 006's contract records is
closed by this change. The canonical goldens of every committed recording are regenerated by
`scripts/ops/canonical_golden.py`, and the diff touches `unit-queued` lines only, which a test
asserts by comparing the regenerated stream with the old one field by field.

## `match-started` carries the population limit

`lobby_presets` gains `population_limit`, read from the engine's lobby settings like the three
presets already there, as a decimal string. Its register datum is the existing
`event.match_started.lobby_presets`; the method text names the new key.

## `starting-attributes` gets its producer

The declared-only kind (006 FR-020) is emitted once per human participant at clock 0, after
`match-started`, by the Tier A decoder (006 research D1; `docs/data-sources.md` §2). Its payload is
006's, `values`, holding only the indices whose meaning is adopted (research R4): `food`, `wood`,
`stone`, `gold` at first. 006's test that the adapter emits neither declared-only kind is the test
that changes, for this kind only; `starting-object` stays declared-only.

The decoder is engine-independent by construction: it reads the inflated header bytes, not the
engine's output, so it lives in `packages/replay-engine` beside the placement decoder and is
golden-tested over every committed recording, including the planted absences
`tests/test_starting_state_anchor.py` already exercises.

## Accounting

006's conservation test is unchanged: no operation is added or lost, because `starting-attributes`
corresponds to no operation and sits outside the count, as `match-started` does.
