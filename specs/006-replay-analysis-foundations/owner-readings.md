# Owner readings — Phase 8

The values that no source the batches read states, for the owner to answer, per FR-022c and
FR-030. Until 2026-10-31 the answer was read from the running game or the Fandom wiki; since the
owner's arbitration of that date (spec Clarifications, Session 2026-10-31) it may come from any
source `docs/data-sources.md` §6 references, read by the owner or by an agent for the owner, and
the "Where read" cell names who read what.
Phase 8's batches add rows; T772 and T774 turn each answered row into a modelled effect. A row is
**open** until its four answer columns are filled. Do not guess a value to close a row.

How to read a value in the game, where the owner chooses to: start a solo game or open the
scenario editor with the civilisation named, reach the age named, research the technologies named,
and read the tooltip of the entity named. If no source shows the value, write `unreadable` and
where it was looked for: the row then becomes an enumerated limit (FR-022b) instead of blocking
promotion.
