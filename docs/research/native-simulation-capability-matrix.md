# Native simulation extraction: capability matrix

- **Feature**: 009 (`specs/009-native-simulation-feasibility/spec.md`, FR-004, FR-010, FR-012)
- **Assessed**: 2026-11-08; companion of `docs/research/native-simulation-feasibility.md`, whose
  section numbers (§) and source numbers this file cites rather than restating them

One row per gameplay fact the platform wants. Four routes are compared:

- **A** the game's own gRPC stream while it replays (CaptureAge's route, §3), DEMONSTRATED by
  third parties, not run here;
- **B** `librematch/genie` (§4), READ IN CODE for build 158041 only, not run;
- **CP** the state checkpoints the game writes into every recording (§6), DEMONSTRATED here on
  three recordings with a tested reader;
- **CL** the command log as the project reads it today (features 006 and 008), the baseline.

Columns. _Availability_ uses FR-004's classes: **direct** (a field of the exposed state),
**snapshots** (reconstructable from successive snapshots), **events** (from an event stream),
**inference** (needs additional inference), **n/a** (not available). _Provenance_ uses FR-012's
vocabulary: `ENGINE_STATE`, `ENGINE_EVENT`, `DETERMINISTIC_DERIVATION`, `COMMAND_LOG`, `INFERRED`,
`UNAVAILABLE`. _Exact_ says whether the value, where available, is the simulation's own value.
_Evidence_ says what stands behind the row: **demonstrated here**, **demonstrated by others**
(cited code), **read in code**, **documented**, or **none**.

## Reading the matrix

- **Nothing on route A was run by this project.** Every A cell is "demonstrated by others" from
  cited third-party code and CaptureAge's own bundle (§3). The rows say what the stream contains
  once decoded; decoding is against a per-build, reverse-engineered model (§3.6, §3.8).
- **Nothing on route B was run.** B is exact by construction for build 158041 and unavailable for
  the project's builds (§4).
- **Route CP is the only engine-state source this project holds today.** It is exact, coarse and
  partial: sums and counts per player, every 500 syncs, from the raw file, for every build.
- **Route CL is intent.** Its exactness is the exactness of an order, never of an outcome; where a
  cell says "proof", feature 008 measured a later order that implies the earlier state.
- **No row is `ENGINE_EVENT` for this project today**, and no row is exact per object. The spec's
  five-scenario criterion (SC-003) is met for resources as a sum and partially for creation and
  death as net counts; the other seven scenarios depend on route A (§7).
