# Asset packs

Licence reference for every directory under `packages/game-assets/`, plus the sources this project
looked at and rejected. All figures were measured **2026-08-30**; the per-pack `LICENCE.md` files are
the normative copies, this file mirrors them for a reader who wants the whole picture in one place —
`scripts/checks/asset_packs.py` asserts the two never drift apart. See
`specs/004-visual-parity/research.md` D3 for the reasoning behind the ruling each pack carries, and
`specs/004-visual-parity/contracts/asset-pack.md` for the five-field record format these entries
follow.

## Packs copied in

One row per directory under `packages/game-assets/`, mirroring that pack's own `LICENCE.md` — the
normative copy — field for field. `scripts/checks/asset_packs.py`'s `check_docs_mirror` parses this
exact table (header naming a `Pack` column plus the five fields, one row per pack) and fails the
build the moment a cell here disagrees with the `LICENCE.md` it mirrors, so an edit to one without
the other is caught before merge rather than discovered by a reader.

Source for each pack: `civilisations` from `SiegeEngineers/aoe2techtree`'s `img/Civs/` (measured
2026-08-30: 59 PNG, each 104×104, re-encoded to WebP, no upscaling — already within the ≤128 px
bound research.md D5 sets); `maps` from `SiegeEngineers/aoe2cm2`'s `public/images/maps/` (435 PNG,
re-encoded to WebP, bound at 256 px on the longest side — source images are 140x140 and already
under the bound); `flags` from `lipis/flag-icons`'s `flags/4x3/` (249 SVG, the rectangular 4x3
aspect-ratio set — the standard "country flag" presentation — filtered to the 249 files whose name
is an official ISO 3166-1 alpha-2 country code; the repository's other 8 two-letter files in that
directory — `cp`, `dg`, `eu`, `ic`, `pc`, `un`, `xk`, `xx` — are organisation, dependent-territory or
placeholder flags outside ISO 3166-1 and were not copied, alongside its 3-letter and hyphenated
regional/subdivision files such as `arab`, `gb-eng`, `es-ct`).

### Player colours — design-system tokens, not a pack

The eight canonical AoE2:DE player colours are not shipped as image files: constitution VI forbids a
hard-coded colour in a component, so they ship as design-system colour tokens instead and carry no
`LICENCE.md` under `packages/game-assets/`. Recorded here because they were sourced and checked the
same way the packs above were.

- **Source**: aoe2companion's `colorHex` across all eight player slots, measured 2026-08-30 against a
  live match (`getRecentMatchHistory` gameId 501455090). Upstream ground truth is the game's own
  `resources/_common/dat/spritecolors.json`, which is not published on the web.
- **Licence**: Not copyrightable — eight RGB triples are facts, below the _Feist_ threshold.
- **Permitted usage**: unrestricted; not a licensed work.
- **Ruling**: **COPY IN**, recorded anyway. See `specs/004-visual-parity/research.md` D3 for the
  eight `color_id` → hex → name values.
- **Checked**: 2026-08-30
