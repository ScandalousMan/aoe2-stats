# Licence record — map minimaps

- **Source**: `SiegeEngineers/aoe2cm2`, `public/images/maps/` (435 PNG, re-encoded to WebP, bound at
  256 px on the longest side — source images are 140x140 and already under the bound).
- **Licence**: None found. The GitHub API reports `license: null` for the repository, and the
  repository's own `README.md` credits the assets directly rather than covering them under its
  (absent) code licence: "Age of Empires © Microsoft Corporation. **Captains Mode for Age of
  Empires** was created under Microsoft's '[Game Content Usage
  Rules](https://www.xbox.com/en-us/developers/rules)' using assets from Age of Empires II, Age of
  Empires III, and Age of Empires IV, and it is not endorsed by or affiliated with Microsoft."
- **Permitted usage**: Microsoft "Game Content Usage Rules" — a revocable, non-exclusive licence to
  use and display Game Content and to create derivative works, strictly non-commercial, requiring the
  notice this project carries in `README.md` and the site footer. Re-encoding to WebP is a derivative
  work, which the Rules permit.
- **Ruling**: **COPY IN**. Constitution X 5.0.0 permits game assets in the repository on the
  non-commercial and disclaimer anchors, "as non-Microsoft fan sites do" — which is this case. No
  openly-licensed AoE2 minimap pack exists, so an SPDX-grant reading would permit nothing at all. The
  residual risk this ruling accepts — GCUR permits display but not the extraction that produced the
  pack upstream — is recorded in `docs/risks.md` R7 and `specs/004-visual-parity/research.md` D3.
